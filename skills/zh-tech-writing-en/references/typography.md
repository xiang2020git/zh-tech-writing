# Detailed Typography Rules

A supplement to the “Typography” section of SKILL.md. Each rule includes an example.

## Numbers

**Thousands separators**: Add half-width commas to numbers with five or more digits; commas are optional for four-digit numbers.

```
公司的实收资本为 ￥1,258,000。
```

**Units**: Add a space between numbers and English units.

```
16 GB 内存
1 h = 60 min = 3,600 s
```

**Currency**: Put the currency symbol before the number, or the Chinese currency name after it.

```
$1,000
1,000 美元
```

**Percent signs**: Use half-width `%`, immediately after the number with no space: `6.5%`.

**Ranges**: Connect endpoints with `～` or “至”, and include units at both ends.

```
132 kg～234 kg
67%～89%
2009 年～2011 年
-20 °C 至 -10 °C
```

**Increases and decreases**: “了” indicates the amount of change; “到” indicates the resulting value.

```
增加到两倍：原来 1，现在 2
增加了两倍：原来 1，现在 3
降低到 80%：原来 100，现在 80
降低了 80%：原来 100，现在 20
```

Express decreases only as percentages; do not say “降低 N 倍”.

## Punctuation

**Full stops**: Put a parenthetical note at the end of a sentence before the full stop.

```
差：请参照第 1.3 节（见第 26 页。）
好：请参照第 1.3 节（见第 26 页）。
```

**Parentheses**: Use full-width `（）` for supplementary explanations, with no spaces before or after.

```
请确认所有连接（电缆和接插件）均已安装牢固。
```

**Colons**: Use full-width `：` for explanations; use half-width `:` for times, such as `8:00`.

**Commas**: Do not run through an entire paragraph using only commas. Use a full stop when an idea is complete.

**Semicolons**: Use only between coordinate clauses.

**Exclamation marks**: Do not use them. Do not repeat them as `！！`.

**Dashes**: Write `——` (the width of two Chinese characters). Prefer commas, colons, or parentheses instead.

**Connecting marks**:
- Use half-width `-` for compounds of two nouns and for figure and table numbers: `氧化-还原反应`, `图 1-1`.
- Use `～` for numerical ranges; see “Ranges” above.

**Line beginnings**: Full stops, commas, enumeration commas, semicolons, colons, question marks, and exclamation marks must not appear at the beginning of a line.

## English

**Abbreviations**: On first occurrence, give the full name and Chinese translation in parentheses; use the abbreviation directly afterward.

```
IOC（International Olympic Committee，国际奥林匹克委员会）
```

**Capitalization**: Capitalize the first letter of each word in proper nouns, and use lowercase for common nouns. Use the official spelling for product and technology names: `GitHub`, `JavaScript`, `macOS`.

**Plurals**: When translating English plurals into Chinese, restore the singular form: `RAMs` → `RAM`.

**Book and article titles**: Change English quotation marks to Chinese title marks in Chinese text: `《航空业的未来》`.
